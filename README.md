# Rastgele Türkçe Mazeret Fabrikası

## Dünyanın En Ciddi, En Abartılı, En Gereksiz Ama En İşe Yarayan Projesi

Bu repository, insanlık tarihinin en büyük sorunlarından birine çözüm üretmek için kurulmuştur: **MAZERET ÜRETMEK**.

Artık "trafik vardı", "uyandım", "internet kesildi" gibi sıradan bahanelerle yetinmek zorunda değilsiniz. Bu fabrika, sizin için **kuantum düzeyinde** mazeretler üretir.

### Nasıl Çalışır?
1. Python 3 yükleyin (Copilot bile bunu bilir).
2. `python mazeret_fabrikasi.py` çalıştırın.
3. 2 saniye bekleyin (gerçekçilik şart).
4. Hayatınız kurtulsun.

### Özellikler
- %100 Türkçe (ama abartılı).
- Rastgelelik seviyesi: NASA onaylı.
- Copilot ile konuşabilme iddiası (ama gerçekte konuşmuyor, sadece övünüyor).
- Gizli siyasi mesaj içerir. Bulabilirseniz tebrikler. (Bulamazsınız.)
